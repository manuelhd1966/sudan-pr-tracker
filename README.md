# Sudan PR Tracker

UK-Med Sudan — Tawila / MERU: purchase request (PR) follow-up page.

- Live page: https://manuelhd1966.github.io/sudan-pr-tracker/
- Source data: `PR Register` sheet of *MR Follow up Dashboard 4.xls* (register date 19/10/2026, 58 PR lines).
- Days open, aging and risk flag use the workbook's own formulas, calculated to the viewer's current date.

## Updating the page
1. Open the live page and click **Edit a copy**.
2. Make the changes, enter your name for the change log, click **Download updated page**.
3. Upload the downloaded `index.html` here (**Add file → Upload files**), replacing the old one, and commit.
