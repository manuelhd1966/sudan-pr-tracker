# Sudan PR Tracker

UK-Med Sudan — Tawila / MERU: purchase request (PR) follow-up page.

- Live page: https://manuelhd1966.github.io/sudan-pr-tracker/
- Source data: `PR Register` sheet of *MR Follow up Dashboard 4.xls* (register date 19/10/2026, 58 PR lines).
- Days open, aging and risk flag use the workbook's own formulas, calculated to the viewer's current date.

## Updating the page
1. Open the live page and click **Edit a copy**.
2. Make the changes, enter your name for the change log, click **Download updated page**.
3. Upload the downloaded `index.html` here (**Add file → Upload files**), replacing the old one, and commit.

## Vendors (due diligence, documents, performance)
- **Vendors** tab: vendor register (IDs `SUP-TWL-0001`…), 15-question due diligence (Yes / No / N/A, automatic score), required documents with expiry dates, and performance evaluations (7 criteria, 1–5).
- Link a vendor to a PR in the PR's **Vendor (register)** field. Required documents then follow the PR's procurement tier.
- Sources for every requirement are listed in **Method & notes → Vendor requirements and their sources** (UK-Med Procurement Policy V3; OCHA SHF Operational Manual; OCHA CBPF Partner Guidance Note on Fraud 2021; UN Security Council Consolidated List).
- This page is public: never enter bank account numbers, ID numbers or personal contact details — record where documents are filed instead.
